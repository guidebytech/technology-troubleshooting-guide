# Browser Troubleshooting Guide

Browser problems can come from extensions, cached data, outdated software, network settings, or a problem with a particular website.

## Start With the Basics

Before changing advanced settings:

1. Reload the affected page.
2. Open the page in a private or incognito window.
3. Try another browser.
4. Restart the browser.
5. Restart the computer if the problem affects multiple applications.

## Check Extensions

Browser extensions can interfere with pages, downloads, logins, and media playback.

Temporarily disable extensions and test the affected page again. If the problem disappears, enable extensions one at a time to identify the likely cause.

## Clear Cached Data

If a website behaves incorrectly while other sites work normally, stale cached data may be involved.

Clear the relevant browser cache and reload the page.

## When to Investigate Further

If the same problem appears across different browsers and devices, investigate the network connection, account settings, or the website itself rather than repeatedly changing browser settings.
