# Display Problem Troubleshooting

Screen problems can range from incorrect display settings to cable, driver, monitor, or hardware issues.

## Check the Simple Causes First

Start by checking:

- Display brightness and basic settings
- Cable connections
- Monitor input selection
- Resolution and refresh-rate settings
- Whether the problem appears before the operating system loads

## Test Another Connection

If possible, test a different display cable, port, or monitor. A comparison test can help determine whether the problem follows the computer or stays with the display equipment.

## Software and Drivers

If the issue started after an operating system or graphics-driver change, review recent updates and the documented compatibility information for the hardware.

Avoid installing random driver packages from unverified websites.

## Persistent Hardware Symptoms

Flickering, physical screen damage, persistent artifacts, or problems that remain across different cables and displays may require professional hardware diagnosis.

Back up important data before performing major system changes.
