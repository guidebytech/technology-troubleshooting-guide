# Internet Connection Troubleshooting

A connection problem can affect one device, several devices, a particular application, or the entire network. Identifying the scope of the problem helps avoid unnecessary changes.

## Identify the Scope

Check whether:

- Other websites load.
- Other devices can connect.
- Only one application is affected.
- The connection repeatedly drops.
- The problem occurs on both Wi-Fi and wired connections.

## Basic Steps

1. Check whether the router or access point shows an obvious error.
2. Restart the affected device.
3. Restart network equipment when appropriate.
4. Test another website or service.
5. Check whether another device has the same problem.

## Wi-Fi Problems

Move closer to the access point and test again. If possible, compare the connection with a wired connection.

If other devices work normally, the issue may be specific to the affected device.

## When to Contact the Provider

If multiple devices lose internet access and local network troubleshooting does not restore service, the issue may be outside the home or office network. At that point, checking the provider's service status or contacting support can be more useful than repeatedly changing device settings.
